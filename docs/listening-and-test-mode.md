# Listening exercise and test mode

Both are fields of a normal lesson `practice` exercise.

## Listening (`"type": "listening"`)

```json
{ "type": "listening", "instruction_ua": "Послухай новину і дай відповіді.",
  "audio": "hr-les-47-news.mp3", "audio_text": "Full text of the recording.",
  "items": [ { "prompt": "Питання українською?", "accepted": ["answer", "alt answer"] } ] }
```

- The learner hears the recording; the text stays hidden until she presses "Показати текст".
- Answers are typed like in a translate exercise. 3-8 items (size rule `listening`, overridable in config `size_rules`).
- `audio_text` is level-audited and voiced by `gen-audio.js` (file name is the `audio` value).

## Test mode (`"test": true` on any exercise)

After "Перевірити" the learner sees the score and red/green fields, but the correct answers are not shown.
Used for mini-tests (Lekcija 48 and later). "Спробувати ще" still clears the fields.

## Dialogue (two voices)

Instead of `audio_text`, a listening exercise can carry `lines`; every line is voiced separately and the files are joined into `audio`:

```json
"lines": [ { "speaker": "A", "voice": "a", "text": "..." }, { "speaker": "B", "voice": "b", "text": "..." } ]
```

Voice `a` is the teacher (`tts_persona` in the language's `config.json`), voice `b` is `tts_persona_b` (must be set before a lesson uses it; `gen-audio.js` refuses otherwise). The learner's "Показати текст" shows the lines with the speakers.

## Choice items (multiple choice, true / false)

A `translate` or `listening` item may carry `choices` (2 or more different options); the learner picks from a list and `accepted` holds the right option(s):

```json
{ "prompt": "Фільм новий.", "choices": ["Правда", "Неправда"], "accepted": ["Неправда"] }
```

Options with Latin letters are level-audited; Ukrainian ones are not.

## Dictation from a word list

`{ "type": "dictation", "words": ["priča", "radnja"], "max": 10 }` dictates words already taught (in this or an earlier lesson; the word needs a note with audio). The validator names a word that cannot be found.

## Digest

For every exercise with `"test": true` the teacher's digest lists every wrong item of the latest attempt (item, expected answer, what was typed), since the learner never saw the answers.

## Reading comprehension (`"type": "comprehension"`)

A long text to read first, then questions; the text stays on screen while she answers.

```json
{ "type": "comprehension", "instruction_ua": "Прочитай текст і дай відповіді.",
  "passage": { "title": "optional", "paragraphs": ["...", "..."] },
  "items": [ { "prompt": "Питання українською?", "accepted": ["answer"] },
             { "prompt": "Твердження.", "choices": ["Так", "Ні"], "accepted": ["Так"] } ] }
```

- 4-10 items (size rule `comprehension`). The text aims at 120-350 words (a nudge, not an error) and is level-audited paragraph by paragraph.
- Items can use `choices` (multiple choice, true / false) like listening items. Ukrainian answers are not level-audited.
- Optional `"audio": "hr-les-NN-<name>.mp3"`: the text read aloud by the teacher's voice (generated by `gen-audio.js`), with a speaker button above the text.
- `"test": true` works here too.
